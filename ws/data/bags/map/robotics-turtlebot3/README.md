# Robotics TurtleBot3 - Modul 1

## Panduan Penggunaan (Quick Start)

1. Clone repositori:
   git clone https://github.com/adindavassyamuzahidin/WSL_1.9-Challenge-.git
   cd WSL_1.9-Challenge-/docker

2. Build image Docker:
   docker compose build

3. Jalankan container:
   docker compose up -d

4. Masuk ke dalam container:
   docker compose exec dev bash
