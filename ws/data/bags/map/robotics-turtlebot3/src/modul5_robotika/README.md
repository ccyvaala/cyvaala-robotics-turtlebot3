# Modul 5 Robotika: LIDAR, IMU, Odometry, dan rosbag2

Repositori ini berisi data eksperimen, skrip analisis Python, dan metadata pengujian robotika Modul 5.

Struktur Folder:
- data/results : Menyimpan file CSV hasil pengujian gerak lurus dan rotasi.
- data/bags : Menyimpan folder rekaman rosbag.
- scripts : Menyimpan skrip analisis data Python.
- metadata.meta.yaml : Informasi metadata eksperimen.
